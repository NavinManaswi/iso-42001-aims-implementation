# 🎯 AIMS Scope (Clause 4 — Context of the Organization)

## Overview

This folder contains artifacts for **Clause 4** of ISO/IEC 42001 — Context of the Organization. These documents define the boundaries of the AI Management System (AIMS).

---

## 📂 Contents

| File | Clause | Description |
|------|--------|-------------|
| `aims-scope-statement.md` | 4.3 | Defines which AI systems, processes, and locations are in scope |
| `interested-parties-register.md` | 4.2 | Maps all stakeholders and their expectations |

---

## 🔑 Key Concepts

### AIMS Scope
The AIMS scope defines:
- **In-Scope AI Systems** — Which systems are governed by the AIMS
- **Out-of-Scope AI Systems** — Which systems are excluded (with justification)
- **Geographic Scope** — Which jurisdictions are covered
- **Organizational Scope** — Which business units and subsidiaries are covered

### Interested Parties
- Customers
- Employees
- Regulators
- Investors
- Vendors
- Society
